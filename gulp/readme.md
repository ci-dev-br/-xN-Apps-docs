# Gulp Ci/Cd

Este arquivo substitui o CI/CD automático do projeto para distribuição manual e local do projeto para ambientes sem Jenkins apenas com os recursos do Node Local.

## Congifurando o Gulp para fluxo de Ci/Cd manual

Crie o arquivo `.env` com as configurações indicadas no arquivo de exemplo. Em caso de ausência de parâmetro será utilizado o recurso da conta do desnvolvedor mediante aprovação ou apenas a etapa que precisa do recurso será ignorada.
