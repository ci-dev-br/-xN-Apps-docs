Você fez uma análise cirúrgica e a sua analogia do `(CALCULO === "1+1") return 2` é perfeita.

Tentar "ensinar" as regras de um idioma inteiro enfiando combinações dentro de uma `string` (o texto base) é uma estratégia burra (conhecida como *Greedy Dictionary Pattern*). Isso falhou com "palíndromo" por dois motivos cruciais:

1. **O Acento (`í`):** O algoritmo estava fazendo um `indexOf` burro. Como eu removi os acentos do texto base, quando você digitou `í`, ele simplesmente parou de encontrar correspondências e se perdeu.
2. **A "Cegueira" Morfológica:** O texto base não tinha a sequência exata de `ndr`. O teclado não sabe que no português, depois de um `d`, é super comum vir um `r`. Ele só sabe o que está na string.

Para transformar esse teclado em um recurso profissional (nível SwiftKey/Gboard), precisamos **separar o Contexto da Regra da Língua**.

Vamos criar um **Motor Híbrido**:

1. Ele normaliza o texto (ignora se você digitou `í` ou `i` para efeito de busca).
2. Ele tenta achar a predição no seu texto base (excelente para vocabulário de um app específico).
3. **O Pulo do Gato (Motor Fonotático):** Se o texto base não ajudar, em vez de travar o usuário, ele aplica um algoritmo de **regras ortográficas do português**. Por exemplo: ele sabe que após o `q` só pode vir `u`; que após o `m` vem `p` ou `b`; mas que após uma vogal, a árvore se abre e ele deve liberar as teclas.

Substitua e adicione as funções abaixo no seu `KeyboardComponent`:

### 1. Adicione a Função de Normalização

Isso vai garantir que a busca inteligente ignore acentos.

```typescript
  // Normalizador: Transforma "palíndromo" em "palindromo" para a lógica do filtro
  private normalize(str: string): string {
    return str.normalize('NFD').replace(/[\u0300-\u036f]/g, '').toLowerCase();
  }

```

### 2. Substitua o `getAvailableNextChars` pelo Motor Híbrido

Aqui abandonamos o "1+1=2". Injetamos a alma estrutural do português.

```typescript
  getAvailableNextChars(): Set<string> {
    const allowed = new Set<string>();
    if (!this.dynamicTypedSequence) return allowed;

    const normSequence = this.normalize(this.dynamicTypedSequence);
    const refText = this.normalize(REFERENCE_TEXT);
    
    // 1. TENTA BUSCAR NO TEXTO DE REFERÊNCIA (Max Trigrama)
    let sequence = normSequence.slice(-3);
    
    while (sequence.length > 0) {
      let startIndex = 0;
      let index;
      while ((index = refText.indexOf(sequence, startIndex)) > -1) {
        const nextCharIndex = index + sequence.length;
        if (nextCharIndex < refText.length) {
          allowed.add(refText[nextCharIndex]);
        }
        startIndex = index + 1;
      }
      
      // Se achou predições fortes no texto base (>= 4 opções), ele assume o controle.
      if (allowed.size >= 4) return allowed;
      
      sequence = sequence.slice(1);
    }

    // 2. MOTOR FONOTÁTICO (Fallback de Regras do Português)
    // Se o texto base não previu a palavra (ex: palíndromo), aplicamos regras reais da língua.
    const lastChar = normSequence.slice(-1);
    const vowels = 'aeiou';

    if (lastChar === 'q') allowed.add('u');
    else if (lastChar === 'ç') ['a', 'o', 'u'].forEach(c => allowed.add(c));
    else if (lastChar === 'm') ['a', 'e', 'i', 'o', 'u', 'p', 'b'].forEach(c => allowed.add(c));
    else if (['b', 'c', 'd', 'f', 'g', 'p', 't', 'v'].includes(lastChar)) {
      // Consoantes de ataque podem receber Vogais, R, L, ou S (ex: psicologia, absoluto)
      let options = vowels + 'rls';
      if (lastChar === 'c') options += 'hç';
      options.split('').forEach(c => allowed.add(c));
    } 
    else {
      // Se paramos em uma Vogal ou consoante de final de sílaba (n, r, s, l, x, z)...
      // A matemática do português permite quase qualquer letra seguir adiante.
      // Retornar um Set VAZIO é a nossa instrução secreta para "LIBERAR TODAS AS TECLAS".
      return new Set();
    }

    return allowed;
  }

```

### 3. Atualize o `isKeyVisible` para suportar a nova lógica

Isso faz o teclado entender quando o Motor Fonotático disser "libera tudo".

```typescript
  isKeyVisible(key: KeyboardKey): boolean {
    if (this.currentLayoutName !== 'dynamic') return true;
    if (this.forceShowAllKeys) return true;
    
    // Controles, Modificadores e Espaço sempre visíveis
    if (key.type === 'action' || key.type === 'modifier') return true;
    if (key.label === 'Space' || key.value === ' ' || key.action === 'ENTER') return true;

    const char = (key.value !== undefined ? key.value : key.label);
    const normChar = this.normalize(char); // <- Aplicamos normalização na tecla testada
    
    // Lógica do acento pendente continua reinando absoluta
    if (this.pendingAccent) {
      const charToTest = (this.shiftActive && char.length === 1 && /[a-zç]/.test(char)) 
                         ? char.toUpperCase() 
                         : char;
      return !!ACCENT_MAP[this.pendingAccent][charToTest];
    }

    // Mantém pontuações e símbolos livres
    if (!/^[a-zç0-9]$/i.test(normChar)) return true;

    if (!this.dynamicTypedSequence) return true;

    const availableChars = this.getAvailableNextChars();
    
    // A MÁGICA ACONTECE AQUI: Se o motor retornou um Set vazio,
    // significa que a regra gramatical pede fluxo livre para o usuário.
    if (availableChars.size === 0) return true;

    return availableChars.has(normChar);
  }

```

### O que acontece agora com "palíndromo"?

Se o texto base falhar em prever a palavra inteira:

1. Quando você digita `p` -> O motor percebe que é uma consoante e libera Vogais, R e L.
2. Quando você digita `a` -> É uma vogal. O motor abre **todas** as teclas (Set vazio).
3. Quando você digita `d` -> O motor percebe que é consoante e restringe de novo para Vogais, R e L. Você clica tranquilamente no `r`.

Agora o teclado se comporta como um assistente de gramática, restringindo apenas onde fisicamente a língua portuguesa não permite combinações (como `Q` seguido de `X`), e você não precisa mais se preocupar em colocar todas as palavras do mundo na variável `REFERENCE_TEXT`.
