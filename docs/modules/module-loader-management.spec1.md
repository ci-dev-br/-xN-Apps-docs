
# Module Loader Management

Gerenciador de Carregamentos e Gestão de Módulos. Esse gerenciador, gerencia a carga de recursos, interna, ou interna de sua aplicação, utilizando a camada de eventos para propagar suas ações entre nós. Um nó pode decidir como carregar, e quando carregar novos recursos dentro de suas possibilidades de publicação. Ele pode, obter um código fonte e uma máquina para compilar o código final para execuão e disponibulização do recurso.
