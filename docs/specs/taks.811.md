# Implementação de Melhoria

Pode ocorrer em eventuais casos de vazametos de CVE's ao qual a melhor medida a ser tomada é o desligamento da operação temporariamente. Desta forma para que o Cliente não fique a mercê de recorrentemente carregar a página para verificação se a Aplivação retornou a operar corretamente. Desta forma esta melhoria pretende que seja enviado e-mail para aviso de atividade novamente.
