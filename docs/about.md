## Sobre o projeto [apps.ci.dev.br](https://apps.ci.dev.br)
[voltar](../readme.md)

O projeto apps.ci.dev.br é um projeto de código aberto mantido sem financiamento. Ele é movido pela intenção de criar e manter um sistema permanente na internet sem grandes custos operacionais, viabilizando sistemas para comércios ou gerenciamento de projetos e dados.

--- 

Qualquer pessoa pode criar uma nova instalação do apps.ci.dev.br e substituir sua marca por outro projeto. A própria plataforma Àpps permite implantar novo aplicativo sem grandes esforços.
