Módulo NestJS via Git

Adicione um repositório Git com uma lib NestJS contendo uma aplicação personalizada. Clona isoladamente e compila em paralelo.

Endereço do Repositório Git (HTTPS ou SSH) link O endereço do Git é obrigatório.
Nome do Módulo NestJS view_module Nome exato da classe exported do Módulo NestJS. O nome do módulo é obrigatório. Branch do Git fork_right
Identificador da Aplicação (appKey) tag Identificador único da aplicação. A chave da aplicação é obrigatória. Nome de Exibição badge
Configurações e Parâmetros do Módulo (JSON) Parâmetros passados para a inicialização e injeção do módulo.
info Este repositório será clonado em uma pasta isolada com git próprio sem mesclar no projeto principal, e sua compilação será executada em paralelo em segundo plano.
