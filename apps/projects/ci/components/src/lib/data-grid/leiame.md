# Componente de Visualização de dados em planilha

A visualização do componente de dados em planilha permite com que dados sejam fatiados ou pivotados Sino instruções Da própria estrutura em relação à forma como eles devem ser lidos agrupados ajustados ou filtrados permitindo que o usuário adicione camadas e filtros No resultado final Entre os nós dapi ou mesmo na camada do banco Dependendo do conjunto de dados que eles seleciona. 

O usuário inicialmente selecionou um conjunto de dados pode ser uma entidade ou qualquer retorno de serviço ou conjunto de dados em memória gerados localmente Esses dados podem ser processados Na memória local se tiver disponível ou Em banco se não houver memória local Existe a possibilidade também de processamento em banco local Porém consome processamento local Localmente não consome rede então Localmente é interessante quando os dados já estão localmente no servidor é interessante qualidade já estão serve o maior custo é enviar os dados Esse custo é tempo. O tempo é o único déficit E pode existir nessa operação A escolha errada causa esse déficit Que são os tratamentos. Seu código funciona é normal feito se ele está vendo ele só está rodando no lugar errado guarde o Para rodar no lugar certo.

É melhor estratégia é ter um catálogo De estratégias de filtragem E a configurações de parâmetro com o tempo vai calibrando qual parte do bloco lógico de executar em qual parte do Sistema. Não seria possível uma fórmula geral pois sempre é possível gerar uma nova forma de padrão Lógico Pode quebrar Completamente a farma de processar Dessa forma só tem como saber como processar depois de saber o que que deve ser processado Não existe uma forma padrão.
