# Chamada

Controle de Chamada Permite controlar o dispositivo para gerenciar chamada telefônica através da entrada e saída de audio do dispositivo servidor. Permitindo alternar entre dispositovos de entrada e saída de audio para direcionamento e gerenciamento de chamadas vinculasdas ao sistema. Chamada também permite chamar Hooks de Auto Atendimento dentro do sistema para direcionamento de atendimento de chamadas por agentes de IA.
